# ClimaTec
Repositório do projeto ClimaTec com acesso à API do site Open-meteo.com

# Objetivo

Aplicativo mobile Android nativo em Java que consome a API Open-Meteo para exibir o
clima atual com base na localização geográfica do usuário.

# Escopo
O sistema deve:
• solicitar acesso à localização;
• obter latitude/longitude;
• buscar o clima atual na Open-Meteo;
• exibir cidade, temperatura, umidade e vento;
• permitir atualização manual.
